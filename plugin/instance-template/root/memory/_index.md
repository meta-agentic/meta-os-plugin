# Layer 2 — Memory

The knowledge base. One directional flow:

```
raw  →  wiki  →  output
capture   refine    deliver
```

| Stage | Folder | Rule |
|-------|--------|------|
| **raw** | [[memory/raw/_index\|raw/]] | Cheap, disposable captures and Claude outputs. Never cited as ground truth. |
| **wiki** | [[memory/wiki/_index\|wiki/]] | Refined, linked, indexed reference. The durable knowledge. |
| **output** | [[memory/output/_index\|output/]] | Finished deliverables: documents, decks, reports. |

## Promotion — the one discipline that matters

Knowledge is trusted only after it is **promoted**: someone (human or agent) takes a `raw/` capture, cleans it, links it into the graph, gives it front-matter, and moves it to `wiki/`. Un-promoted notes stay in `raw/`.

## Cross-vault memory

This is the memory above the projects. Project-local vaults can still exist and are federated by linking, not copied (see [[vaults/_index|vaults/]]). Durable cross-project knowledge is promoted here.
