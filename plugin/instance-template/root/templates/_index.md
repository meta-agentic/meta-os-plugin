# Templates

Note templates. With Obsidian's Templates core plugin (folder set to `templates/`), insert one from the command palette. `<% ... %>` fields are Templater syntax. These files were copied here by `/meta-os:init` and are this instance's own: change them freely.

| Template | For |
|----------|-----|
| [[templates/project\|project]] | A new node in [[projects/_index\|projects/]] |
| [[templates/source\|source]] | A promoted research or paper note in `memory/wiki/research/` |
| [[templates/note\|note]] | General promoted knowledge: project summaries, decisions, cross-cutting facts |
| [[templates/skill-note\|skill-note]] | A wiki note about one use of a skill |
| [[templates/skill-learnings\|skill-learnings]] | The standing learnings note for one skill (one per skill, in `memory/wiki/skills/`) |
| [[templates/daily\|daily]] | Daily capture note |
| [[templates/heartbeat\|heartbeat]] | A scheduled self-check capture (lands in `memory/raw/`) |
